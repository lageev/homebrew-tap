# Homebrew Tap

Homebrew tap for apps published by [lageev](https://github.com/lageev).

## Studio Mini

```sh
brew install --cask lageev/tap/studio-mini
```

Studio Mini is a lightweight macOS app for building Android projects, managing Git branches, and installing APKs on connected devices.

## FocusMic

```sh
brew install --cask lageev/tap/focusmic
```

FocusMic keeps the macOS default audio input locked to your preferred microphone.
